API Reference

Tài liệu API

Đặc tả kỹ thuật các điểm cuối (endpoints), phương thức yêu cầu và định dạng dữ liệu JSON.

POST /api/run

Kích hoạt duy trì hoặc khôi phục bù chuỗi cho tài khoản Locket bằng UID cá nhân. Hoàn toàn không yêu cầu API Key hay Token bí mật, an toàn tuyệt đối khi sử dụng cho Siri Shortcuts hoặc Webhook tự động.

Mẹo lấy mã UID: Truy cập vào Bảng Quản Lý, bấm nút Chi tiết trên thẻ tài khoản của bạn để sao chép mã UID.
Headers
Content-Type: application/json
Request Body (JSON)
{
  "uid": "YOUR_LOCKET_UID"
}
Response 200 (Duy trì thành công) 200 OK
{
  "success": true,
  "alreadyUpdated": false,
  "restoredDates": [],
  "updatedToday": true,
  "streakCount": 206,
  "message": "Duy trì chuỗi hôm nay thành công! Chuỗi hiện tại: 206 ngày."
}
Response 200 (Hôm nay đã được giữ chuỗi trước đó) 200 OK
{
  "success": true,
  "alreadyUpdated": true,
  "restoredDates": [],
  "updatedToday": false,
  "streakCount": 206,
  "message": "Chuỗi hôm nay (206 ngày) đã được duy trì trước đó rồi, không cần chạy lại."
}
Response 429 (Giới hạn tần suất gọi - Cooldown 30s) 429 Too Many Requests
{
  "success": false,
  "cooldown": true,
  "remainingSeconds": 24,
  "message": "Thao tác quá nhanh! Vui lòng đợi 24 giây nữa trước khi tiếp tục."
}
Response 400 / 401 / 404 (Lỗi yêu cầu) Error
{
  "success": false,
  "message": "Mã UID không hợp lệ hoặc tài khoản chưa được thêm vào hệ thống."
}
Ví dụ cURL
curl -X POST https://YOUR_DOMAIN/api/run \
  -H "Content-Type: application/json" \
  -d '{"uid": "YOUR_LOCKET_UID"}'
