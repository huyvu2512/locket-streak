API Reference

Tài liệu API

Đặc tả kỹ thuật các điểm cuối (endpoints), phương thức yêu cầu và định dạng dữ liệu JSON.

POST /api/run

Kích hoạt duy trì hoặc khôi phục bù chuỗi cho tài khoản của bạn bằng UID cá nhân.

Request Body (JSON)
{
  "uid": "YOUR_LOCKET_UID"
}
Response 200 (Thành công)
{
  "success": true,
  "alreadyUpdated": false,
  "restoredDates": [],
  "updatedToday": true,
  "streakCount": 206,
  "message": "Duy trì chuỗi hôm nay thành công! Chuỗi hiện tại: 206 ngày."
}
Response 400 / 500 (Lỗi)
{
  "success": false,
  "message": "Thiếu UID người dùng hoặc phiên đăng nhập đã hết hạn."
}
